# C Programming — My Learning Journey

Hi everyone! I'm **Syed Akasha Hashmi**, a first-year Computer Science Engineering student at Satavahana University.

This repository documents my journey of learning C programming, from the fundamentals to functions and arrays. It contains small example programs, practice problems, and projects that I build as I improve my programming skills.

My goal is to understand the fundamentals clearly, practise consistently, and gradually build more advanced projects.

**Example:** Store five numbers in an array and calculate their sum.

File: `05-arrays/array_sum.c`

## ▶️ How to Run the Programs

You can compile and run these programs using GCC or another C compiler.

1. Open a terminal in the directory containing the program.
2. Compile the file:

   ```bash
   gcc filename.c -o program
   ```

3. Run the compiled program:

   **Windows**
   ```bash
   program.exe
   ```

   **Linux/macOS**
   ```bash
   ./program
   ```

Replace `filename.c` with the path to the C file you want to run.
